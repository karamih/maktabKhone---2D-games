# Python Game Development with Pygame

مجموعه‌ای از تمرین‌ها و پروژه‌های عملی دوره آموزش بازی‌سازی با پایتون و کتابخانه Pygame، منتشرشده در مکتب‌خونه.

در این دوره، مفاهیم اصلی بازی‌سازی دوبعدی را به‌صورت عملی یاد می‌گیریم و با پیاده‌سازی مثال‌های مختلف، آن‌ها را در پروژه‌های واقعی به کار می‌بریم.

## Topics Covered

* Game Loop, FPS and Delta Time
* Keyboard and Mouse Input
* Movement, Vectors and Collision Detection
* Working with Images, Sprites and Sprite Sheets
* Sprite Animation
* Sprite Groups and Object Management
* Enemy Movement and Collision Handling
* Health, Damage and Invincibility
* Coins, Collectibles and Score Systems
* Game UI and HUD
* Building a Snake Game

## Projects and Exercises

این مخزن شامل تمرین‌های کوچک برای یادگیری مفاهیم مختلف، نمونه‌هایی از انیمیشن شخصیت‌ها، سیستم سلامتی و آسیب، تعامل با دشمنان، جمع‌آوری سکه و آیتم‌ها، سیستم امتیازدهی و پروژه‌های عملی بازی‌سازی است.

یکی از پروژه‌های اصلی این مجموعه، بازی مار (Snake Game) است که در آن مفاهیمی مانند حرکت، جمع‌آوری آیتم‌ها، افزایش امتیاز، رشد مار و سیستم Boost در کنار یکدیگر استفاده شده‌اند.

## Requirements

* Python 3
* Pygame

Install Pygame:

```bash
pip install pygame
```

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd <repository-directory>
```

Run any exercise or project using Python:

```bash
python main.py
```

The entry-point filename may differ between exercises and projects.
